## Problem-solving checklist
1. Restate the problem and constraints.
2. Identify input size and target complexity.
3. Pick the data structure and pattern.
4. Walk through examples and edge cases.
5. Code the simplest correct version.
6. Analyze time and space complexity.
7. Optimize only after correctness is clear.

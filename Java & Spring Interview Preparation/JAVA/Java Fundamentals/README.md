## Applied practice
- Primitive wrappers: explain autoboxing, unboxing, null risks, equality pitfalls, and collection usage.
- Pass-by-value: show how Java copies primitive values and object references during method calls.
- Strings: compare string literals, `new String`, `StringBuilder`, `StringBuffer`, and concatenation in loops.
- Modern Java: connect enhanced switch, records, sealed classes, and pattern matching to cleaner domain modeling.
- Coding drills: after each concept, write one tiny example and record mistakes in [DAILY_PROBLEM_LOG.md](../../../DAILY_PROBLEM_LOG.md).

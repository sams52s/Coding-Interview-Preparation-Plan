## Deep-dive practice
- Java modules: explain `module-info.java`, exports, opens, migration risk, and library compatibility.
- Reflection and proxies: connect annotation-driven frameworks to runtime method interception and generated behavior.
- Class loading: describe parent delegation, context class loaders, unloading, and classpath conflicts.
- Diagnostics: practice thread dump, heap dump, and GC-log reasoning with [Performance Engineering](../../Performance%20Engineering/README.md).
- Modern Java: use records, sealed classes, pattern matching, virtual threads, and structured concurrency when they simplify real code.

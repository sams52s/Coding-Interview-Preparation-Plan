## Practice strategy
- For each study topic, read the matching notes first, then answer the linked question-bank file without looking at the answer.
- For coding questions, explain brute force, optimized approach, complexity, and edge cases.
- For system design questions, cover requirements, APIs, data model, architecture, scaling, consistency, failure handling, observability, security, and trade-offs.
- For behavioral answers, prepare concise STAR stories and connect them to real project or learning experiences.

## Deep practice prompts
- Explain Netflix-style streaming with CDN, encoding, entitlement, and recommendations.
- Explain Uber-style ride matching with geo-indexing, trip state, and payment idempotency.
- Explain Instagram-style feed fanout, media storage, ranking, and privacy.
- Walk through a production incident using root cause, mitigation, and prevention.
- Refactor bad code into testable Java/Spring components.
- Compare CRDTs, vector clocks, consensus, sagas, and outbox patterns.
